# BookNest - eCommerce Bookstore

A responsive front-end bookstore built with React, Vite, CSS, and Lucide React.

## Features
- Responsive homepage and navigation
- Book catalogue with sample products
- Search by book title or author
- Filter by category
- Add books to cart
- Increase/decrease quantities and remove items
- Automatic cart total calculation
- Mobile-friendly layout

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Build
```bash
npm run build
```

## Notes
This is a front-end demonstration. Checkout is a demo action only; no payment processing or order storage is configured. Book images are loaded from Unsplash URLs and therefore require an internet connection.
